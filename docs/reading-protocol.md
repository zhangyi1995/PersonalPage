# 阅读协议：这个系列的笔记怎么写

方法取自 Mortimer Adler 与 Charles Van Doren 的《如何阅读一本书》，落到本仓库的具体规则。写任何一篇读书笔记前先读这一页。

## 三个层次怎么用

| 层次 | 在这个系列里的做法 | 时机 |
| --- | --- | --- |
| 检视阅读 | 先整本通读一遍：目录、序言、每章开头与结尾。目的是拿到全书骨架，不在任何一处停留 | 动笔写第一篇之前 |
| 分析阅读 | 逐章精读，每章产出一篇笔记 | 每一篇 |
| 主题阅读 | 跨书比较同一议题（如《人月神话》与《没有银弹》《人件》） | 全书读完之后 |

检视阅读不能跳过。跳过它的典型后果是陷在第一章反复打磨，后面越拖越慢——这正好是《人月神话》第一章描述的"焦油坑"。

## 每篇笔记的结构

分析阅读的规则决定了四节的顺序，不要调换：

| 小节 | 对应规则 | 写什么 |
| --- | --- | --- |
| 这一章讲了什么 | 找结构（先弄清作者在说什么） | 用自己的话复述论证链，不抄原文 |
| 我的判断 | 评论（前提是已经读懂） | 认同什么、怀疑什么，理由要落到具体四类：知识不足／知识错误／逻辑不通／分析不完整 |
| 和我手上的工作有什么关系 | 第四个基本问题 | 对应自己的项目或经历，这一段最有价值 |
| 一句话记住 | 用一句话说出它在谈什么 | 全章压缩成一句，可被引言页或首页引用 |

## 四个基本问题

写每篇之前先答一遍，答不上来说明还没读懂：

1. 这一章整体在谈什么？
2. 作者细部说了什么，怎么说的？
3. 说得有道理吗——全部有道理，还是部分有道理？
4. 这跟我有什么关系？

## 硬性约束

- **短引为主**：原文只在必要时引一两句，并标注章节；成段摘录是版权问题，也不是读书笔记的价值所在。
- **复述先于评判**：没能在"这一章讲了什么"里讲清楚作者的论证，就不该进入"我的判断"。
- **区分事实与己见**：说"作者错了"必须给理由；说"我不认同"要讲清是立场分歧还是论据不足。
- **允许判断过时**：书里的例子多来自 1960–70 年代，指出哪些结论只在当时环境下成立，是笔记应尽的义务。
